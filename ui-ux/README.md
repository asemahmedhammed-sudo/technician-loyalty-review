# MK KASHIYAMA — Interactive Client Review

نسخة عرض تفاعلية للعميل مبنية على 7 شاشات HTML مصدّرة من UX Pilot.

## تشغيل محلي
افتح ملف `index.html` في المتصفح، مع اتصال بالإنترنت لتحميل Tailwind وFont Awesome وخط IBM Plex Sans Arabic.

## GitHub Pages
ارفع **محتويات هذا المجلد** إلى مجلد `uxpilot-demo` في المستودع `technician-loyalty-review`، ثم افتح:

https://asemahmedhammed-sudo.github.io/technician-loyalty-review/uxpilot-demo/

يجب تمكين GitHub Pages على الفرع /main عند الجذر، وإلا تختلف طريقة النشر.

## الشاشات
- لوحة الإدارة
- إدارة الأصناف
- ترميز النقاط
- دفعات الباركود
- طلبات التركيب
- إدارة الفنيين
- مستويات الولاء

## التفاعلات
- روابط التنقل في Sidebar وأداة "جولة النظام".
- البحث والتصفية واختيار السجلات داخل كل شاشة بحسب النسخة الأصلية.
- إضافة وتعديل الأصناف محليًا بذاكرة المتصفح.
- حفظ قيمة النقطة محليًا، وعرض القيمة المحتسبة في صفحة الأصناف.
- بقية إجراءات الاعتماد والرفض والتوليد والطباعة محاكاة تصميمية؛ لم تُنفّذ معاملات على خادم حقيقي.

## تنبيهات مهمة
- لا يوجد تسجيل دخول فعلي أو قاعدة بيانات أو API.
- بيانات العملاء والفنيين وأكواد المكافآت توضيحية.
- الباركود المرئي ليس بالضرورة ترميز Code 128 فعليًا أو صالحًا للمسح؛ ممنوع استخدامه للطباعة الإنتاجية.
- النتائج المحفوظة في localStorage في متصفح المراجع فقط ولا تنتقل لمستخدم آخر.
- ملفات CDN الخارجية تتطلب اتصالًا بالإنترنت. هذا النموذج **ليس تطبيقًا إنتاجيًا**.
- لم تُضمَّن شاشة طلبات المكافآت لعدم إرفاق ملف HTML الخاص بها في هذه الحزمة.
