معاينة توضيحية: الخطوط على الملصق للعرض فقط ولا تمثل ترميز Code 128 مُتحقَّقًا. الطباعة الفعلية تتطلب ترميزًا مطابقًا للمعيار واختبار قابلية المسح على الطابعة المعتمدة.

قبل الطباعة

  • رقم الصنف MK-10025 ظاهر نصيًا على كل ملصق
  • الرمز الفريد مطبوع بـ Code 128 مع نصه القابل للقراءة
  • تُطبع الملصقات للرموز غير المستخدمة فقط (210)
  • باركود الصنف الثابت لا يُستخدم مكان الرمز الفريد

الطباعة لا تغيّر حالة أي رمز. يبقى الرمز غير مستخدم حتى تُعتمد المطالبة عبر مسار التركيب.

هذه الشاشة نموذج تصميمي تعرض بيانات عينة وأرقامًا توضيحية لأغراض العرض فقط. الرموز المعروضة ليست رموزًا حقيقية ولم تُنشأ أو تُسجَّل على أي خادم، ورسوم الباركود توضيحية وليست ترميز Code 128 مُتحقَّقًا.
